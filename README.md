# Buckshot Roulette для R.E.P.O.

Мод добавляет дилера, общий пул боевых/холостых патронов, дробовик, ножовку, наручники, глушилку, адреналин и четыре ценности.
Предметы покупаются в магазине, ценности спавнятся на карте, дилер появляется по штатным правилам раунда.
Отладочного автозапуска и тестового спавна в моде нет.

Сборка пакета: соберите плагин в конфигурации Release и выполните `python scripts/package_release.py`.
Пакет появится в `releases/`. Для публикации используйте `scripts/publish_thunderstore.py`, передавая
токен только через переменную окружения `THUNDERSTORE_TOKEN`.

## Адреналин

Один заряд, 5–10 тысяч в магазине. Взять в руки и нажать клавишу взаимодействия (E).
На 10 реальных секунд мир замедляется до ×0,1: враги, другие игроки, анимации и падающие предметы.
Для использовавшего игрока компенсируются управление, физика тела, анимации и работа предметов в руках.
Удерживаемый им физический объект также получает компенсацию, включая переносимого игрока в кувырке.

Активацию подтверждает хост: проверяются удержание, живой игрок, оплаченный предмет и активный уровень.
Повторное применение во время собственного эффекта не расходует второй инъектор. Несколько игроков могут
использовать адреналин независимо: у каждого свои 10 секунд, общий коэффициент остаётся ×0,1.
Состояние передаётся надёжным событием; поздние клиенты запрашивают оставшееся время, смена хоста сохраняет
исходные сроки. После смерти пользователя, окончания эффекта или выхода с уровня компенсация снимается.

Реализация использует общий Unity timeScale с сохранением реальной частоты физики и отдельной компенсацией
тел/сил/таймеров пользователя. Это заменяет раннее предложение из плана ограничиться множителями скорости:
одних множителей недостаточно для корутин, атак и падающих предметов. Photon передаёт скорости в реальных
секундах. Совместимость с другими модами, управляющими timeScale или заменяющими физику, ещё не проверена.
Сценарии и границы проведённых проверок: [проверки адреналина](tests/ADRENALINE.md).

## Глушилка

Держите предмет и нажмите E (клавишу взаимодействия). Три применения, цена в магазине 35–40 тысяч.
Радиус по умолчанию 45 м с учётом штатного множителя слуха моба; настройка `Jammer.Radius`.
Слышащий монстр уходит от источника на половину расстояния до него. Стены и край NavMesh ограничивают
точку ухода; оглушённые враги и враги без достижимого пути пропускаются. При достижении точки,
застревании или истечении тайм-аута возвращается обычный ИИ.

Одно применение тратит заряд даже без подходящих целей. Остаток сохраняется между уровнями,
показывается штатными тремя полосами заряда в HUD и лампами на модели. Предмет не перезаряжается
и не отдаёт заряд другим батареям; после третьего импульса исчезает.
Хост проверяет удержание предмета и интервал 1,5 с между импульсами; новые клиенты запрашивают
снимок остатка без воспроизведения старого звука.

## Исправления 0.1.3

Холостой дробовика теперь не создаёт дробь и не наносит урон никому; слышен хлопок и виден дым.
Боевой и холостой расходуют по одному заряду. Это новое согласованное правило заменяет прежний
обязательный боевой урон по обычным мобам.

Наручники находят тело и скелет в соседних ветках префаба, работают без сетевого ID в одиночной игре,
проверяют дистанцию до поверхности тела и препятствия. У Trudge блокируется также начатая атака.
Голос телефона стал выше и медленнее; известным русским именам добавлены ударения и пауза после звонка.

Проверки: 58 тестов логики, 6 тестов наручников и 5 тестов исполнения выстрела; последние две группы
используют заменители Unity API и не подтверждают работу физики, Photon и звука в игре.
Игровые сценарии: [проверка 0.1.3](tests/HOTFIX-0.1.3.md).

## История исправлений 0.1.2

Наручники, адреналин, глушилка и ножовка больше не наследуют разрушение аптечки при ударах.
Игровые модели и коллайдеры увеличены: наручники ×1,6, адреналин ×1,7, глушилка ×1,8.
Наручники держатся плоскостью к игроку, глушилка — экраном к игроку. Искры ножовки привязаны к линии
отпила ствола и следуют за перемещаемым оружием.

Глушилка временно управляет навигацией отступающего врага, приостанавливая конфликтующие команды
его обычного ИИ. Оглушение обрабатывается штатно; после ухода, смерти или тайм-аута временное управление снимается.

Выстрел нашего дробовика снимает один патрон общего пула даже при промахе. Результат сохраняется
для всех дробин: по дилеру применяется этот результат, по обычным мобам — штатный боевой урон.
Холостой по дилеру блокирует весь удар, включая оглушение и толчок, а не только потерю здоровья.
Пустой пул с дилером обновляется после завершения выстрела, без дилера — после подзарядки.
Повторная зарядка уже существующего пула не создаёт второй анимации.

## Сборка

Для локального теста `python scripts/start_test_game.py` собирает отдельный профиль в `scratch/playtest`
и запускает обычный забег: автоперехода в одиночный уровень больше нет, предметы мода покупаются
в магазине, ценности мода спавнятся по штатным правилам карты, дилер — по штатным вероятностям раунда.
После подготовки профиля можно запускать `start-test.cmd` обычным двойным щелчком. Если запуск агента
ограничивает Steam/PlayerPrefs, запускать этот файл нужно из обычного сеанса Windows с работающим Steam.

Для ценности-пива добавлены короткие звуки удара по алюминию при повреждении и разлива
при разрушении. Файлы `assets/audio/beer_*.wav` обязательны вместе с остальным каталогом Audio;
цель `DeployToProfile` копирует их автоматически. Звуки синтезированы, игровое прослушивание ещё требуется.
Глушилка переделана по предоставленной фотографии. Сверка остальных моделей и оригинальные
фото находятся в [art/references](art/references/README.md).

Нужны .NET SDK, установленная игра R.E.P.O., BepInEx и REPOLib. Плагин компилируется против DLL
игры и выбранного профиля, поэтому передайте пути явно:

```powershell
dotnet build BuckshotRoulette.sln `
  -p:GameDir="C:\Path\To\REPO" `
  -p:ProfileDir="C:\Path\To\REPO\BepInExProfile"
```

Обычная сборка создаёт артефакт в `src/BuckshotRoulette.Plugin/bin` и не устанавливает его в игру.
Для отдельного развёртывания выполните:

```powershell
dotnet msbuild src/BuckshotRoulette.Plugin/BuckshotRoulette.Plugin.csproj `
  -t:DeployToProfile `
  -p:GameDir="C:\Path\To\REPO" `
  -p:ProfileDir="C:\Path\To\REPO\BepInExProfile"
```

Профиль должен содержать `BepInEx`, `0Harmony.dll` и `Zehs-REPOLib/REPOLib.dll`.

## Проекты

- `src/BuckshotRoulette.Plugin` — Unity/BepInEx-плагин.
- `src/BuckshotRoulette.Logic` — независимая игровая логика.
- `tests/BuckshotRoulette.Logic.Tests` — unit-тесты чистой логики.
- `assets` — исходные Blender-модели и экспортированные игровые ассеты.

Сетевые игровые сценарии требуют отдельной проверки в R.E.P.O. с хостом и клиентом.
