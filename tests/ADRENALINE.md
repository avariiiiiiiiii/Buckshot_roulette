# Проверки адреналина

Сделано автоматически:

- Сборка плагина против DLL установленной игры и REPOLib.
- Unit-тесты: реальные сроки действия, отклонение повторной активации, независимые сроки двух игроков,
  восстановление снимка при позднем подключении/смене хоста, атомарное отклонение неверных снимков,
  нечисловые часы и расчёт компенсации свободного падения.
- Офлайн-проверка IL (`scratch/adrenaline/ilcheck`): production-транспайлер применён к IL 720 методов
  установленных DLL; проверено покрытие PlayerController, PhysGrabber, ItemGun и PhotonTransformView,
  преобразование 34 ожиданий корутин. Это проверка преобразований, а не запуск Harmony в Unity.

Команды из корня проекта:

```powershell
dotnet test tests/BuckshotRoulette.Logic.Tests/BuckshotRoulette.Logic.Tests.csproj --no-restore
dotnet run --project scratch/adrenaline/ilcheck -- "$PWD"
```

Офлайн-проверка использует локальные пути игры и профиля buckshot. Mono-версия Harmony из BepInEx не
может копировать методы Unity под CoreCLR; для этой проверки IL декодируется отдельно и передаётся
в production-транспайлер. Эта офлайн-проверка не запускает физический движок и PUN-сеанс.

Дополнительно 2026-11-14 игра была запущена через отдельный профиль `scratch/playtest`. В Unity/Mono
Harmony применил патчи без ошибок, зарегистрировались все пять предметов и четыре ценности. Затем игра
завершилась: SteamApi_Init не смог определить установку Steam, а запись PlayerPrefs была запрещена средой.
До уровня и проверки эффекта в действии запуск не дошёл. Журналы сохранены в `scratch/launch/failed-sandbox`.

Обязательные игровые проверки (пока не выполнены):

| Сценарий | Ожидается |
| --- | --- |
| Одиночная игра, E с инъектором в руках | Один расход; 10 секунд по внешним часам, затем восстановление времени. Цена 5–10к. |
| Активирующий — хост, затем клиент | Обычный бег/прыжок/падение пользователя; остальные движутся в десять раз медленнее. |
| Падение и бросок свободной ценности | Мир и гравитация замедлены; после окончания нет разгона или остаточного замедления. |
| Столкновение переносимого предмета с неподвижной ценностью | Проверить передачу импульса и урон при контакте тел с разной компенсацией. |
| Поднять, перехватить и отпустить ценность | В руках активного игрока перемещается нормально, после отпускания замедляется. |
| Стрельба, перезарядка, отдача у активного игрока | Работа оружия, задержки и физика нормальные, остальные таймеры мира замедлены. |
| Спасти игрока в кувырке | Его можно схватить и унести; компенсация переносимого тела снимается при отпускании. |
| Два пользователя со сдвигом 4 секунды | Первый эффект заканчивается на 10-й секунде, второй на 14-й; мир всё время ×0,1. |
| Повторный запрос и второй инъектор у уже активного игрока | Второй заряд не расходуется, срок не продлевается. |
| Попытка в магазине / чужим не удерживаемым предметом | Нет активации и расхода. |
| Позднее подключение, смена хоста, отключение пользователя | Получение остатка, сохранение исходного срока; отключённый пользователь исключается хостом. |
| Смена уровня, смерть, выход в меню | Все принадлежащие эффекту настройки времени, скоростей и damping восстановлены. |
| Дилер и несколько ванильных типов атак | Движение, атаки, корутины и клипы замедляются согласованно. |

Отдельно проверить сторонние моды с собственными физическими циклами/таймерами и изменением timeScale.
