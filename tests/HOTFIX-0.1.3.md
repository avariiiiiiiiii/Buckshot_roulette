# Проверка 0.1.3

Автоматические проверки: 58 тестов логики, 6 source-linked тестов наручников с заменителями Unity,
5 source-linked тестов исполнения выстрела. Сборка против установленных DLL REPO.
Живой прогон Unity/Photon и прослушивание голоса этой версии ещё не выполнены.

После перезапуска проверить версию 0.1.3 в scratch/playtest/BepInEx/LogOutput.log.

| Сценарий | Ожидается |
| --- | --- |
| Холостой в обычного моба, дилера, игрока или ценность | Хлопок и дым без дроби, урона, оглушения и толчка цели. |
| Боевой в моба | Обычный залп, один расход пула и батареи на все дробины. |
| Последний патрон, затем зарядка | С дилером новый пул сразу; без дилера после зарядки, без двойного показа. |
| Наручники на Trudge в одиночной игре | Применение с дистанции до 2 м до тела, расход один раз, отключение атаки, руки связаны. |
| Наручники через стену или далеко | Не применяются и не расходуются. |
| Наручники и дробовик у клиента Photon | Хост принимает запрос только от удерживающего игрока, результат совпадает на клиентах. |
| Поднять телефон | После звонка короткая пауза, затем различимое имя; проверить русскую и английскую локаль. |
