# Проверка исправлений 0.1.2

Автоматически: сборка против игровых DLL; 52 unit-теста, включая расход при промахах, общий результат
дробин, отсутствие второго списания при попадании и отсутствие пересечения с выстрелом другого оружия.
Офлайн-проверка патчей навигации покрывает EnemyTick, EnemyAnimal, EnemyRunner и EnemyStateRoaming;
EnemyRigidbody, Enemy и компоненты анимации не приостанавливаются. Проверен булев префикс EnemyHurt,
который может остановить весь холостой удар до штатного оглушения/силы/урона.

Игровая проверка новой версии ещё не проведена. В уже запущенной игре остаётся старый код.
После перезапуска в `scratch/playtest/BepInEx/LogOutput.log` должна загрузиться версия 0.1.2.

| Проверка | Ожидается |
| --- | --- |
| Бросить наручники, адреналин, глушилку и ножовку в стену | Сохраняются предмет и его применение; расход по E всё ещё удаляет использованный предмет. |
| Удерживать глушилку, применить 3 раза | HUD 3 → 2 → 1 → 0, лампы соответствуют; экран обращён к игроку. |
| Зарядка глушилки от станции и другого предмета, попытка отдачи заряда | Заряды не пополняются и не отдаются. |
| Глушилка рядом с клопом/Tick на открытом NavMesh | Идёт от источника на половину расстояния; обычный ИИ не сбрасывает маршрут и не вращает его на месте. |
| Уход моба у стены, оглушение/смерть во время ухода | Не проходит сквозь стену; после остановки/оглушения/смерти штатное управление продолжает работать. |
| Отпилить ствол неподвижного и удерживаемого дробовика | Искры на линии отпила, следуют за оружием. |
| Без дилера выпустить весь дробовик в стену, затем подзарядить | Старый пул пуст, после зарядки один новый пул и один показ состава. |
| С дилером исчерпать общий пул | Один показ нового пула после выстрела; последующая зарядка не дублирует его. |
| Попадание в дилера патроном пула Blank | Нет урона, оглушения и толчка; результат делят все дробины, списание одно. |
| Тот же Blank по обычному мобу | Боевой урон, согласно исходному ТЗ. |
| Стрельба другим оружием по дилеру | Расход общего пула, без списания полос батареи нашего дробовика. |
| Выстрел в магазине | Пул раунда не создаётся и не расходуется. |
