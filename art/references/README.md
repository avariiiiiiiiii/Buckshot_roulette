# Оригинальные предметы Buckshot Roulette

Фотографии предоставлены пользователем из `Downloads` и скопированы в `original`.
Это основные визуальные референсы для следующих изменений моделей.

Сверка 2026-11-14:

| Предмет | Результат |

Обновлённые три ценности: `../previews/valuables_reference.png`.
Редактируемые модели: `../models.blend`, воспроизводимый экспорт: `../valuables_pipeline.py`.
Проверка формата, масштаба, UV, текстур и геометрии: `python art/verify_valuables.py` из корня проекта.
Глушилка: `../previews/jammer.png`, редактируемый источник `../jammer.blend`.
Адреналин: `../previews/adrenaline.png`, источник `../adrenaline.blend`, экспорт `../adrenaline_pipeline.py`.
Проверка модели адреналина: `python art/verify_adrenaline.py` из корня проекта.

Звуки пива — собственные синтезированные приближения Foley, генератор `../beer_audio.py`.
В Unity назначаются через копию штатного `PhysAudio`: breakLight/Medium/Heavy — алюминий,
destroy — разлив жидкости. Штатные сетевые события игры распространяют воспроизведение;
отдельного звукового RPC нет. Звук в реальном игровом сеансе пока не прослушан.
