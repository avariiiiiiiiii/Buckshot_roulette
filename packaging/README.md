# Buckshot Roulette

Bring the Dealer and Buckshot Roulette items into R.E.P.O.

## Content

- Dealer enemy with music, a shotgun and a shared pool of live and blank shells.
- Dealer's Shotgun: live shells deal damage; blanks produce a pop and smoke without hurting any target.
- Hacksaw: doubles the next shot or melee attack.
- Handcuffs: a single use disables hand attacks on a nearby enemy with hands.
- Ultrasonic Jammer: three charges; nearby enemies retreat away from the source.
- Adrenaline: a single use slows the world for ten real seconds while its user moves normally.
- Beer, cigarettes, expired medicine and a phone that names the nearest monster.

Hold a tool and press the interaction key (E by default) to use it. Items appear in the shop;
valuables and the Dealer use normal level spawning. Debug auto-start and test spawning are off by default.

## Installation

Install with Thunderstore Mod Manager or r2modman; dependencies are installed automatically.
All players should install the same version and dependencies. Restart the game after updating.
For manual installation, install BepInEx and REPOLib, then copy the package's plugins directory into BepInEx/plugins.

## Early release

Version 0.1.4 removes all debug spawning: items are bought in the shop, valuables spawn on maps,
the Dealer spawns by the regular round rules. Automated checks pass, but the latest changes still
need in-game and multiplayer verification.
Adrenaline compatibility with other mods that alter time or physics has not been verified.

Report issues and find source code at https://github.com/avariiiiiiiiii/Buckshot_roulette.

## По-русски

Мод добавляет дилера, общий пул боевых и холостых, дробовик, ножовку, наручники, глушилку,
адреналин и четыре ценности. Холостой не наносит урон никому. Предметы используются в руке
клавишей взаимодействия (обычно E). Предметы покупаются в магазине, ценности лежат на карте,
дилер появляется по штатным правилам раунда — тестового спавна в моде больше нет.
Это ранний выпуск: последние исправления требуют проверки в игре и по сети.
